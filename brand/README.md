# Dropfit 통일 기준

사용자가 보는 Dropfit은 어디서나 같아야 합니다. 이 폴더가 그 기준이고, 점검은 자동으로 돕니다.

- 기준 아이콘: `master/` (11/3 확정 '하늘 선'). `rounded-1024.png`는 둥근 판, `full-*.png`는 같은 그림을 모서리까지 채운 macOS 26용 층(밝음·선·어두움). 모든 크기에서 고리 포함.
- 확정 색: `palette.json`
- 보이는 곳 장부: `touchpoints.json` (새 그림·새 페이지는 여기에 먼저 올림)
- 확정값 지문: `ledger.json` (보이는 파일 15개의 지문과 파일별 색 목록)

## 점검

- PR마다·main 반영마다: `python3 brand/check.py` — 아이콘이 기준 그림과 같은지(밝은·어두운 바탕), 모든 페이지의 아이콘 연결, 미리보기 그림 주소, 랜딩·appcast·zip 버전, 금지어·말씨·AI 말투 7가지(진심 강조 상투어·예스러운 낮춤말·광고식 반문·끊어 쓰기·참여 끄는 질문·번역투·영어와 내부 용어), 확정 뒤 바뀐 파일·zip 크기 변화, 장부에 없는 새 색, 400px·1280px 폭 가로 넘침. 합격 수치는 품질 기술서(Claude Doc) 3장.
- 매일 09:00 KST: `python3 brand/check.py --live` — 공개 사이트 파일이 main과 같은지.
- 하나라도 다르면 실패로 표시되고 GitHub가 알림 메일을 보냅니다.

## 바꿀 때

1. 바꾸고 싶은 것을 시안으로 보여 정훈 확정.
2. 반영 후 `python3 brand/check.py --confirm`으로 확정값을 새로 기록(PR에 지문 변경이 함께 보임).
3. 앱 쪽 접점(아이콘 크기별·동그라미 그림·설치 방법 페이지)은 Mac의 `Support/tools/control.sh`가 같은 기준으로 점검.
