## 사용법
1. 이미지·PDF나 폴더를 화면에 떠 있는 **Dropfit**으로 드래그합니다.
2. 펼쳐진 포맷 중 하나 위로 드래그합니다.
3. 놓으면 원본 옆에 새 파일이 생기고, 원본은 그대로입니다.

포맷: **JPG · PNG · HEIC · TIFF · GIF · PDF**

## 설치
1. 다운로드한 zip을 열면 생기는 `Dropfit` 폴더에서 Dropfit을 더블클릭합니다.
2. “인터넷에서 다운로드된 앱입니다”라는 창에서 **[열기]**를 누릅니다. Apple 공증을 받은 앱이라 처음 한 번만 이 창이 뜹니다.
3. “응용 프로그램 폴더로 옮기겠습니까?”에서 **[옮기기]**를 누르면 설치가 완료됩니다.

> macOS 14 Sonoma 이상 · Apple 실리콘과 Intel 모두 지원
