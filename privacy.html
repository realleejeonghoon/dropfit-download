출시 알림 이메일은 신청한 분의 요청에 따라 출시 메일을 보내는 데에만 씁니다. 다른 광고 메일은 보내지 않습니다.

2. Dropfit 앱이 하는 일

  • 파일: 변환과 자르기는 모두 Mac 안에서 일어납니다. 파일과 파일 이름을 어디에도 보내지 않습니다.
  • 설정: 포맷·용량 같은 설정은 Mac 안에만 저장합니다.
  • 업데이트 확인: 새로운 버전이 있는지 확인할 때 GitHub 서버에 업데이트 목록 파일 하나를 요청합니다. 이때 다른 웹사이트에 접속할 때와 같이 IP 주소와 Dropfit 버전이 GitHub 서버 기록에 남습니다. Mac 기종이나 사용 기록은 보내지 않습니다. 자동 확인은 Dropfit 설정의 ‘업데이트’에서 끌 수 있습니다.
  • 피드백 보내기: Mac의 메일 앱을 열 뿐입니다. 보내기 전에 내용을 모두 확인하고 고칠 수 있습니다.
